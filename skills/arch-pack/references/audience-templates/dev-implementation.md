# Dev Implementation Template

Purpose: provide enough design detail for engineering to start safely.

Required outputs in design mode:

- 4 forced markdown files.
- `design-doc.md`.
- `实施方案.md` with 17 chapters.
- diagrams referenced by the design.

Rules:

- Include rollout, rollback, test, observability, and compatibility.
- Link every implementation task to impact/options evidence.
- Do not generate code, DDL, CI, IaC, clients, or service skeletons.
- Use `not_applicable: <reason>` when a chapter truly does not apply.

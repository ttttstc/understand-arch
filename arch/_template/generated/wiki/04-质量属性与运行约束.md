# 04-质量属性与运行约束

> 本页回答“这个系统为什么不能随便改”，重点在 NFR、部署、运行时和组织约束。

## 关键质量属性

说明：

- 可靠性
- 性能 / 延迟
- 成本
- 安全 / 合规
- 可观测性

## 运行时约束

说明：

- 关键配置或运行限制
- 容量、资源、隔离、限流等约束

## 部署与发布约束

说明：

- 主要部署单元
- 发布顺序
- 回滚上的硬限制

## 组织与治理约束

说明：

- banned patterns
- compliance redlines
- network boundaries
- naming conventions / tech radar 中最 relevant 的部分

## 读者应获得的结论

- 当前系统最重要的非功能约束是什么
- 哪些约束会直接改变设计选择
- 哪些地方的变更需要特别谨慎

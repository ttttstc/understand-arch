# 架构基线概览

这是任何人进入项目后应先读的一页。它是稳定的人类入口，不是自由发挥的长文。

首次 `/arch-onboard` 后，应由 `arch-analyze` 和 `arch-pack` 刷新为正式内容；新增事实必须来自 `specs/*.yaml`、`change-requests/*` 或 `decisions/*`。

## 1. 系统是什么

说明：

- 系统目标
- 系统边界
- 当前主要场景

## 2. 主要仓库与组件

说明：

- 主要仓库
- 核心组件
- 各自职责

## 3. 关键接口与依赖

说明：

- 关键 API / 事件 / 消息
- 关键依赖关系
- 外部依赖摘要

## 4. 数据与所有权

说明：

- 关键数据模型
- 数据所有权
- 读写边界

## 5. 部署与运行约束

说明：

- 主要部署单元
- 运行时关键约束
- 对发布、回滚、网络边界有影响的约束

## 6. 风险与技术债

分开写：

- Top 风险
- Top 技术债

## 7. 关键决策与近期变更

说明：

- 重要 ADR
- 最近活跃 CR
- 哪些变化正在改变当前架构

## 8. 基线新鲜度与已知未知项

说明：

- `last_scanned_commit`
- `freshness_status`
- 当前最重要的 known unknowns

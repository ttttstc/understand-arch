# 02 - 现状架构

> 来源: `evidence/依赖与链路图谱.yaml` + `diagrams/`

## C4 - Container

![Container 图](../diagrams/container.mmd)

部署单元:
- `api` (Go HTTP server,4 节点,通常 < 10% CPU)
- `click-aggregator` (Go worker,单节点 — 见 R-002)
- `postgres-shortlink` (主从,自建)
- `redis-shortlink` (**单点** — 见 R-001)

外部依赖:无(纯内网服务)。

## 设计风格与主要关注点

- 风格: 单体服务 + REST API + 异步聚合 worker
- 主要关注: redirect 延迟 / 点击数据不丢失 / abuse 防护

## 已知偏离

- Redis 应该 HA,目前单点 — R-001
- click-aggregator 应该 XREADGROUP,目前 XREAD — R-002
